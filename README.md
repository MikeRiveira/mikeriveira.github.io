# mikeriveira.github.io

Source for my portfolio site: **https://mikeriveira.github.io/**

A single static page (plain HTML, CSS and a little JavaScript, no build step) served by GitHub Pages. It covers my role in dealership IT, impact highlights, featured projects and the tools I use day to day.

| Path | What it is |
|---|---|
| `index.html` | The whole site |
| `assets/*.jpg` | Project preview images |
| `assets/og-image.png` | Link preview image for LinkedIn, Slack, etc. |
| `assets/favicon.svg` | Site icon |
